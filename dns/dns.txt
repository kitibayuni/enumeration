========================
 DNS / Zone Notes
========================

[SOA Record]
- Defines who is responsible for the domain and how DNS is managed.
- Quick check:
  dig soa <www.domain_example.com>

[Zone Files (BIND)]
- Common location: /etc/bind/<filename>
- View: cat /etc/bind/<filename>
- Options to inspect for misconfigurations/vulns:
  * allow-query       -> which clients may query the zone
  * allow-recursion   -> recursion allowed? (open resolver risk)
  * allow-transfer    -> AXFR allowed? (full zone leak risk)
  * zone-statistics   -> may expose operational info

[dig Usage]
- Query a specific nameserver:
  dig <type> <zone> @<dns_server_ip>
  Example: dig ns inlanefreight.htb @10.129.14.128
- Query all records:
  dig any inlanefreight.htb @10.129.14.128
- Zone transfer (if allowed):
  dig axfr <zone> @<dns_server_ip>

[Step-by-step DNS enumeration (practical)]
1) Pull all records for the zone (look for interesting hostnames):
   dig any <domain> @<dns-ip>
   → collect discovered names (e.g., dev.example.com, app.example.com)

2) Attempt zone transfers for discovered names / subzones:
   dig axfr <discovered-subdomain-or-zone> @<dns-ip>
   → a successful AXFR leaks the full zone.

3) Automated enumeration with dnsenum (wordlist + DNS server):
   dnsenum --dnsserver <dns-ip> --enum -p 0 -s 0 -o subdomainsfound.txt -f <wordlist.txt> <target-namespace>
   - `--dnsserver` : use the target resolver
   - `-f <wordlist>`: wordlist for brute/guessing
   - `-o <file>`   : save discovered subdomains

4) Validate & filter results:
   - Detect wildcards (query random-nonexistent.<domain>).
   - Resolve discovered names to IPs.
   - Probe live services (httpx, nmap) only on authorized targets.

[Subdomain Discovery Notes]
- ffuf (HTTP) finds hostnames with running webservers (HTTP/HTTPS response).
- DNS-level tools (massdns, dnsx, altdns, amass, subfinder) reveal DNS records even if no webserver exists.
- Best practice: combine DNS enumeration (find names) + HTTP probing (confirm live web services).

[Quick tips]
- If AXFR succeeds, harvest the zone — it's the fastest way to enumerate FQDNs.
- Pay attention to TXT/SPF records (mail flow hints).
- Check NS A records (e.g., NS pointing to 127.0.0.1 is suspicious).
- Always have authorization before enumerating or probing.
